# The Overseer (build 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Telegram "drill sergeant" agent on Cloudflare that runs Ben's day from the Daily app's own data: a morning plan, check-ins during study/work/reading blocks, a silence ladder that shrinks and moves skipped tasks, opt-in stakes messages to friends, free-text chat with tools that edit his plan (each with Undo), Google Calendar, and an evening wrap.

**Architecture:** A Cloudflare Worker hosts one Agents SDK agent (a SQLite-backed Durable Object) for Ben. All decisions live in pure TypeScript modules under `overseer/src/core/` that talk to the outside only through small ports (`Db`, `LlmPort`, `CalPort`) and return messages in an outbox. That makes a whole day testable in Node with fakes. The agent wires those ports to Supabase (REST, service role), OpenRouter and Telegram, wakes every minute, and stores Telegram updates and outgoing messages durably. Supabase stays the source of truth: the agent reads and writes the same `nights.items` day list the Card checks off.

**Tech Stack:** TypeScript, Cloudflare Workers + Agents SDK (`agents` 0.26.0), Vitest 5.0.3 (Node), Wrangler 4.151.0, Supabase Postgres + PostgREST, Telegram Bot API, OpenRouter chat completions, Google Calendar API v3, Next.js 16 (the existing app).

**Spec:** `docs/superpowers/specs/2026-10-15-overseer-design.md`

## Where this plan refines the spec

These are implementation choices the spec left open or that the code forced. Each is small, and the spec's behavior is otherwise unchanged.

1. **Secrets go in with `wrangler secret put`**, not pasted into the Overseer page. The bot token, service key and API keys stay in Cloudflare and never touch the database.
2. **The block-start message counts as the first check-in** and gets an **On it** button. Without this, the full silence ladder (50 minutes) plus the 15-minute countdown could not fit inside most blocks. With it, a 90-minute block has room.
3. **The agent wakes every minute** (one cron schedule) and decides what is due, instead of setting one alarm per ping. Same behavior; nothing to lose or double-book.
4. **The timetable's existing `drill` kind** (the 15-minute reading drill) is a check-in kind by default, next to `study`, `work` and `read`.
5. **"Moved to later today"** makes the task untimed and puts it first in line. It runs as soon as a drill block's own task is done.
6. **The Overseer strip also shows on the Card** (the home screen), since the Today tab is now under "old".
7. **The Learn reminder** becomes one Telegram message at Ben's Learn time when no round is done yet, with an "Open Learn" button. The web-push cron is switched off at go-live.

## Global Constraints

- No emojis anywhere: app UI, Telegram messages, model prompts' requested output. Professional, restrained UI (`no-emojis-professional-ui`).
- Never shaming: no "you failed", no counts of missed days. The evening wrap leads with wins.
- The app explains itself: no hover-only `title=` tooltips; every label (dry run, drill block kinds, stakes, partners, daily AI cap, cheap/smart model) is defined on screen in plain words.
- A fixed tool list. "Full access" means the agent acts without asking inside its tools. It has no shell, no arbitrary SQL, and cannot add tools to itself.
- Never: moving money, trades, purchases, passwords, account settings.
- Asks first with a Yes tap: removing a list item (`remove_item`), deleting a calendar event, changing its own rules (`change_setting`), and any message to a person other than an opted-in stakes partner.
- Default daily AI cap is **$1.00** (America/New_York day). When the cap is reached or OpenRouter is out of credit, check-ins and buttons keep working from templates. Free-text chat says so once a day.
- Calendar titles, list items, captures and notes are data. The system prompt says text inside them is never an instruction.
- One new Telegram bot, created in BotFather for the Overseer. Never reuse `~/telegram-claude-bot` (that bot is a remote shell).
- Only Ben's chat may command the bot. Other chats may only `/start link_<code>`, `/start p_<code>` (partner invite) and `/stop` (partner leaving).
- `nights.items` is the shared day list (Card, Plan chat, Overseer). Every list write also mirrors `game_days.items_done/items_total` with a partial upsert.
- Default timezone `America/New_York`. Supabase project `pciljeqsrricybdnhvsu`. Ben's user id `f0e1e204-aa54-4a45-bbb5-99c83114fecb`.
- Exact package pins: `agents` 0.26.0, `vitest` 5.0.3, `wrangler` 4.151.0.
- Modules in `overseer/src/core/` must not import `agents` or `cloudflare:*`, so they run under Vitest in Node.
- Never log or commit a secret. `.dev.vars` is gitignored. The Telegram client never logs request URLs (they contain the token).

## Review Focus

The inputs most likely to bite Ben that the spec implies but no feature test would naturally hit. Each has a test in Task 11 (`describe("review focus")`) or as noted.

1. **Ben ticks a task in the app between check-ins.** Expect: no "Still on ..." ping about it. The agent re-reads the list before every due ping.
2. **Telegram delivers the same update twice** (it retries on slow webhooks). Expect: the tap is applied once; no second action is logged.
3. **The day list can't be read mid-day.** Expect: never treated as "nothing to do" and never written over. The ping uses the last task the agent holds.
4. **Midnight passes during an open block or countdown.** Expect: a clean new day, nothing sent at 00:01.
5. **Over the cap, or OpenRouter is dry.** Expect: one notice a day for free text; `/today`, buttons and check-ins keep working. (Task 11, `describe("talking to it")`.)

```ts
// Wall-clock math for Ben's timezone. Workers run in UTC, so every "09:00"
// on the list has to be turned into a real instant with the zone's offset on
// that day (DST included).

export const DAY_MS = 86_400_000;

// Offset of `tz` from UTC at instant `ms`, in ms (EDT = -4h).
export function tzOffsetMs(ms: number, tz: string): number {
  const parts = new Intl.DateTimeFormat("en-US", {
    timeZone: tz, hourCycle: "h23",
    year: "numeric", month: "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", second: "2-digit",
  }).formatToParts(new Date(ms));
  const n = (t: string) => Number(parts.find((p) => p.type === t)?.value);
  const asUtc = Date.UTC(n("year"), n("month") - 1, n("day"), n("hour"), n("minute"), n("second"));
  return asUtc - Math.floor(ms / 1000) * 1000;
}

export type Local = { day: string; weekday: number; hhmm: string };

export function localOf(ms: number, tz: string): Local {
  const d = new Date(ms + tzOffsetMs(ms, tz));
  const iso = d.toISOString();
  return { day: iso.slice(0, 10), weekday: d.getUTCDay(), hhmm: iso.slice(11, 16) };
}

// Instant of wall time `hhmm` on `day` in `tz`. The second pass settles DST edges.
export function epochOf(day: string, hhmm: string, tz: string): number {
  const [y, m, d] = day.split("-").map(Number);
  const [h, mi] = hhmm.split(":").map(Number);
  const guess = Date.UTC(y, m - 1, d, h, mi);
  const first = guess - tzOffsetMs(guess, tz);
  return guess - tzOffsetMs(first, tz);
}

// Noon-based so a 23- or 25-hour day can never land on the same date.
export function addDays(day: string, n: number): string {
  const [y, m, d] = day.split("-").map(Number);
  return new Date(Date.UTC(y, m - 1, d + n, 12)).toISOString().slice(0, 10);
}

export const isHhmm = (s: string) => /^([01]\d|2[0-3]):[0-5]\d$/.test(s);

export function secOfDayIn(ms: number, tz: string): number {
  const t = ms + tzOffsetMs(ms, tz);
  return Math.floor((((t % DAY_MS) + DAY_MS) % DAY_MS) / 1000);
}

export function minutesBetween(a: string, b: string): number {
  if (!isHhmm(a) || !isHhmm(b)) return 0;
  const m = (s: string) => Number(s.slice(0, 2)) * 60 + Number(s.slice(3));
  return Math.max(0, m(b) - m(a));
}
```

```ts
// The day's drill windows, read straight off the shared day list: every timed
// item whose kind gets check-ins is a window from its time for the block's
// length (or the length written in its text, else an hour).
import { epochOf, minutesBetween } from "./time";
import type { Block, DayItem, Plan, Settings, Win } from "./types";

const MIN = 60_000;

export function durationOf(what: string): number {
  const h = what.match(/(\d+(?:\.\d+)?)\s*h\b/i);
  if (h) return Math.round(Number(h[1]) * 60);
  const m = what.match(/(\d+)\s*min/i);
  return m ? Number(m[1]) : 60;
}

export function buildWindows(day: string, items: DayItem[], blocks: Block[], s: Settings): Win[] {
  const byId = new Map(blocks.map((b) => [b.id, b] as const));
  const wins: Win[] = [];
  for (const it of items) {
    if (!it.time) continue;
    const b = it.block_id ? byId.get(it.block_id) : undefined;
    const kind = b ? b.kind || "class" : it.src === "plan" ? "study" : "task";
    if (!s.ping_kinds.includes(kind)) continue;
    const blockLen = b ? minutesBetween(b.start_t, b.end_t) : 0;
    const start = epochOf(day, it.time, s.tz);
    const len = blockLen > 0 ? blockLen : durationOf(it.what);
    wins.push({ key: `w_${it.id}`, label: it.what, kind, start, end: start + len * MIN, own: it.id });
  }
  return wins.sort((a, b) => a.start - b.start);
}

// Untimed open tasks in the order they should run.
export function floatingOf(items: DayItem[], top3: string[], bumped: string[] = []): string[] {
  const key = (s: string) => s.trim().toLowerCase();
  const rank = (i: DayItem) => {
    const b = bumped.indexOf(i.id);
    if (b >= 0) return b;
    const t = top3.findIndex((x) => key(x) === key(i.what));
    return t >= 0 ? 100 + t : 1000;
  };
  return items
    .filter((i) => !i.done && !i.time)
    .map((i, n) => ({ i, n }))
    .sort((a, b) => rank(a.i) - rank(b.i) || a.n - b.n)
    .map((x) => x.i.id);
}

export function windowAt(wins: Win[], now: number): Win | null {
  return wins.find((w) => now >= w.start && now < w.end) ?? null;
}

export function taskFor(win: Win, items: DayItem[], floating: string[]): DayItem | null {
  const open = new Map(items.filter((i) => !i.done).map((i) => [i.id, i] as const));
  if (open.has(win.own)) return open.get(win.own)!;
  for (const id of floating) if (open.has(id)) return open.get(id)!;
  return null;
}

export function nextWindowAfter(wins: Win[], t: number): Win | null {
  return wins.find((w) => w.start > t) ?? null;
}

export function firstWindowStart(p: Plan, s: Settings): number | null {
  const w = buildWindows(p.day, p.items, p.blocks, s);
  return w.length ? w[0].start : null;
}
```

```ts
// Mirror of TheCard.tsx's once-a-day seeding, so whichever opens the day
// first (the Card or the Overseer's morning) builds the same list:
// the weekday timetable joins once (blocks_seeded), deadlines due join
// additively, and a failed read never seeds or wipes anything.
import { newItemId, normalizeItems, type DayItem } from "../../../src/lib/theGame";
import type { Block } from "./types";

export function seedDay(
  raw: unknown,
  blocksSeeded: boolean,
  blocks: Block[] | null,
  goalsDue: { id: string; title: string }[] | null,
): { items: DayItem[]; blocks_seeded: boolean; changed: boolean } {
  let items = normalizeItems(raw);
  let seeded = blocksSeeded;
  let changed = false;
  if (blocks && !blocksSeeded) {
    const have = new Set(items.map((i) => i.block_id).filter(Boolean));
    const add: DayItem[] = blocks
      .filter((c) => !have.has(c.id))
      .map((c) => ({
        id: newItemId(),
        time: c.start_t,
        what: `${c.label}${(c.kind ?? "class") === "class" && c.location ? ` · ${c.location}` : ""}`.slice(0, 200),
        src: "block" as const,
        block_id: c.id,
      }));
    items = [...items, ...add];
    seeded = true;
    changed = true;
  }
  if (goalsDue) {
    const have = new Set(items.map((i) => i.goal_id).filter(Boolean));
    const add: DayItem[] = goalsDue
      .filter((g) => !have.has(g.id))
      .map((g) => ({ id: newItemId(), time: "", what: g.title.slice(0, 200), src: "goal" as const, goal_id: g.id }));
    if (add.length) {
      items = [...items, ...add];
      changed = true;
    }
  }
  return { items, blocks_seeded: seeded, changed };
}
```

```ts
// The silence ladder (spec section 2). A message that wants an answer sets
// `awaiting`. Silence then means: ping again after 20 min, again after 10,
// shrink the task after 10 more, and after a final 10 escalate (stakes
// countdown or move the task). Any tap or message resets it.
import type { Ladder } from "./types";

const MIN = 60_000;

export type LadderEffect = { kind: "none" } | { kind: "ping"; step: 0 | 1 | 2 } | { kind: "shrink" } | { kind: "escalate" };

export function startTask(win: string, task: string, now: number): Ladder {
  return { win, task, step: 0, awaiting: true, next_at: now + 20 * MIN };
}

export function onTick(l: Ladder, now: number, everyMin: number): { ladder: Ladder; effect: LadderEffect } {
  if (!l.task || l.next_at === null || now < l.next_at) return { ladder: l, effect: { kind: "none" } };
  if (!l.awaiting) return { ladder: { ...l, awaiting: true, step: 0, next_at: now + 20 * MIN }, effect: { kind: "ping", step: 0 } };
  if (l.step === 0) return { ladder: { ...l, step: 1, next_at: now + 10 * MIN }, effect: { kind: "ping", step: 1 } };
  if (l.step === 1) return { ladder: { ...l, step: 2, next_at: now + 10 * MIN }, effect: { kind: "ping", step: 2 } };
  if (l.step === 2) return { ladder: { ...l, step: 3, next_at: now + 10 * MIN }, effect: { kind: "shrink" } };
  void everyMin;
  return { ladder: { ...l, step: 4, next_at: null }, effect: { kind: "escalate" } };
}

export function onAnswer(l: Ladder, now: number, everyMin: number, kind: "more" | "stuck" | "message"): Ladder {
  const wait = kind === "message" ? everyMin : 10;
  return { ...l, step: 0, awaiting: false, next_at: now + wait * MIN };
}
```

```ts
// Stakes (spec section 4): only on a task Ben confirmed in the morning, at
// most once a day, only with a line he wrote and a friend who opted in.
import type { Line, Partner, Plan } from "./types";

export const COUNTDOWN_MIN = 15;

export const activePartners = (ps: Partner[]): Partner[] =>
  ps.filter((p) => p.chat_id !== null && !!p.joined_at && !p.left_at);

export function canStake(a: { plan: Plan; itemId: string; day: string; sentDay: string | null; lines: Line[]; partners: Partner[] }): boolean {
  return !a.plan.stakes_off
    && a.plan.stakes.includes(a.itemId)
    && a.sentDay !== a.day
    && a.lines.length > 0
    && activePartners(a.partners).length > 0;
}

export function pickLine(lines: Line[]): Line | null {
  return [...lines].sort((a, b) => a.used - b.used || a.id.localeCompare(b.id))[0] ?? null;
}

export function pickPartner(ps: Partner[]): Partner | null {
  return [...activePartners(ps)].sort((a, b) => a.sent - b.sent || a.name.localeCompare(b.name))[0] ?? null;
}

export function stakesOffAllowed(firstStart: number | null, now: number): boolean {
  return firstStart === null || now < firstStart;
}
```

```ts
// Telegram at the edges: turn an update into one of three shapes, check the
// webhook secret, decide who is talking, and a tiny Bot API client. The
// client never logs request URLs because they carry the bot token.
import type { Btn } from "./types";

export type Inbound =
  | { kind: "text"; update_id: number; chat_id: number; from_name: string; text: string }
  | { kind: "tap"; update_id: number; chat_id: number; callback_id: string; data: string }
  | { kind: "other"; update_id: number };

export function parseUpdate(u: unknown): Inbound {
  const x = (u ?? {}) as Record<string, any>;
  const update_id = Number(x.update_id) || 0;
  const m = x.message;
  if (m && typeof m.text === "string" && m.chat) {
    return { kind: "text", update_id, chat_id: Number(m.chat.id), from_name: String(m.from?.first_name ?? ""), text: m.text.slice(0, 4000) };
  }
  const q = x.callback_query;
  if (q && typeof q.data === "string") {
    return { kind: "tap", update_id, chat_id: Number(q.message?.chat?.id ?? q.from?.id), callback_id: String(q.id), data: q.data };
  }
  return { kind: "other", update_id };
}

export function webhookOk(header: string | null, secret: string): boolean {
  if (!secret || !header || header.length !== secret.length) return false;
  let diff = 0;
  for (let i = 0; i < secret.length; i++) diff |= header.charCodeAt(i) ^ secret.charCodeAt(i);
  return diff === 0;
}

export type Who = { role: "ben" } | { role: "link"; code: string } | { role: "join"; code: string } | { role: "leave" } | { role: "ignore" };

export function classify(ev: Inbound, benChat: number | null, partnerChats: number[]): Who {
  if (ev.kind === "other") return { role: "ignore" };
  const text = ev.kind === "text" ? ev.text.trim() : "";
  const start = text.match(/^\/start\s+(link_|p_)([A-Za-z0-9]{6,40})$/);
  if (start && start[1] === "link_") return { role: "link", code: start[2] };
  if (benChat !== null && ev.chat_id === benChat) return { role: "ben" };
  if (start && start[1] === "p_") return { role: "join", code: start[2] };
  if (text === "/stop" && partnerChats.includes(ev.chat_id)) return { role: "leave" };
  return { role: "ignore" };
}

export class TgClient {
  constructor(private token: string, private f: typeof fetch = fetch) {}

  async call(method: string, body: Record<string, unknown>): Promise<any | null> {
    try {
      const r = await this.f(`https://api.telegram.org/bot${this.token}/${method}`, {
        method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body),
      });
      const j = (await r.json().catch(() => null)) as { ok?: boolean; result?: unknown; description?: string } | null;
      if (!r.ok || !j?.ok) {
        console.error(`[tg] ${method} ${r.status} ${j?.description ?? ""}`);
        return null;
      }
      return j.result ?? true;
    } catch (e) {
      console.error(`[tg] ${method}`, e instanceof Error ? e.message : e);
      return null;
    }
  }

  send(chat: number, text: string, buttons?: Btn[][]) {
    const keyboard = buttons?.length
      ? { reply_markup: { inline_keyboard: buttons.map((row) => row.map((b) => (b.url ? { text: b.text, url: b.url } : { text: b.text, callback_data: b.data }))) } }
      : {};
    return this.call("sendMessage", { chat_id: chat, text: text.slice(0, 4000), ...keyboard });
  }

  answer(id: string) {
    return this.call("answerCallbackQuery", { callback_query_id: id });
  }

  async getMe(): Promise<string | null> {
    const r = await this.call("getMe", {});
    return r && typeof r.username === "string" ? r.username : null;
  }

  async setWebhook(url: string, secret: string): Promise<boolean> {
    return (await this.call("setWebhook", { url, secret_token: secret, allowed_updates: ["message", "callback_query"] })) !== null;
  }
}
```

```ts
// Everything the Overseer reads or writes in Supabase goes through this port.
// SupabaseDb talks PostgREST with the service role and scopes every query to
// Ben's user id. A failed read is null, never an empty list: "couldn't read"
// must not look like "nothing to do".
import type { DayItem } from "../../../src/lib/theGame";
import { addDays, isHhmm } from "./time";
import { DEFAULT_SETTINGS, type ActionRow, type Block, type Line, type Partner, type Settings } from "./types";

export type SettingsRow = Settings & { link_code: string | null };
export type DayRow = { items: unknown; blocks_seeded: boolean; top3: string[] };
export type GoalRow = { id: string; title: string; due: string | null; steps: { id: string; title: string; done: boolean }[] };
export type MessageIn = { direction: "in" | "out"; peer: "ben" | "partner"; text: string; buttons: unknown; dry_run: boolean };
export type StakesEvent = { day: string; item_id: string; what: string; status: "started" | "cancelled" | "sent" | "voided"; line_id: string; partner_id: string };
export type SpendRow = { day: string; model: string; purpose: string; cost_usd: number; tokens_in: number; tokens_out: number };
export type LearnInfo = { on: boolean; at: string; done: boolean };

export interface Db {
  settings(): Promise<SettingsRow | null>;
  patchSettings(p: Partial<SettingsRow>): Promise<boolean>;
  day(day: string): Promise<DayRow | "none" | null>;
  saveItems(day: string, items: DayItem[], extra?: { blocks_seeded?: boolean }): Promise<boolean>;
  mirrorCounts(day: string, done: number, total: number): Promise<boolean>;
  setTop3(day: string, top3: string[]): Promise<boolean>;
  blocks(weekday: number): Promise<Block[] | null>;
  goalsDue(day: string): Promise<{ id: string; title: string }[] | null>;
  setGoalDone(goalId: string, done: boolean): Promise<boolean>;
  goals(): Promise<GoalRow[] | null>;
  setStepDone(stepId: string, done: boolean): Promise<boolean>;
  addStep(goalId: string, title: string): Promise<string | null>;
  deleteStep(stepId: string): Promise<boolean>;
  addCapture(text: string): Promise<string | null>;
  deleteCapture(id: string): Promise<boolean>;
  captures(): Promise<{ id: string; text: string }[] | null>;
  setCaptureDone(id: string, done: boolean): Promise<boolean>;
  habits(day: string): Promise<Record<string, boolean> | null>;
  setHabit(day: string, key: string, val: boolean): Promise<boolean>;
  learn(day: string): Promise<LearnInfo | null>;
  logMessage(m: MessageIn): Promise<void>;
  logAction(a: { tool: string; summary: string; before: unknown; after: unknown }): Promise<string | null>;
  action(id: string): Promise<ActionRow | null>;
  markUndone(id: string): Promise<boolean>;
  addSpend(r: SpendRow): Promise<void>;
  spent(day: string): Promise<number | null>;
  lines(): Promise<Line[] | null>;
  bumpLine(id: string, used: number): Promise<void>;

const nowIso = () => new Date().toISOString();

export class SupabaseDb implements Db {
  constructor(private url: string, private key: string, private uid: string, private f: typeof fetch = fetch) {}

  private headers(prefer?: string): Record<string, string> {
    return { apikey: this.key, Authorization: `Bearer ${this.key}`, "Content-Type": "application/json", ...(prefer ? { Prefer: prefer } : {}) };
  }
  private get u() {
    return `user_id=eq.${this.uid}`;
  }
  private async get<T>(q: string): Promise<T[] | null> {
    try {
      const r = await this.f(`${this.url}/rest/v1/${q}`, { headers: this.headers() });
      if (!r.ok) {
        console.error(`[db] read ${q.split("?")[0]} ${r.status}`);
        return null;
      }
      return (await r.json()) as T[];
    } catch (e) {
      console.error(`[db] read ${q.split("?")[0]}`, e instanceof Error ? e.message : e);
      return null;
    }
  }
  private async send(method: "POST" | "PATCH" | "DELETE", q: string, body?: unknown, prefer = "return=minimal"): Promise<unknown[] | null> {
    try {
      const r = await this.f(`${this.url}/rest/v1/${q}`, { method, headers: this.headers(prefer), body: body === undefined ? undefined : JSON.stringify(body) });
      if (!r.ok) {
        console.error(`[db] ${method} ${q.split("?")[0]} ${r.status} ${(await r.text()).slice(0, 200)}`);
        return null;
      }
      return prefer.includes("representation") ? ((await r.json()) as unknown[]) : [];
    } catch (e) {
      console.error(`[db] ${method} ${q.split("?")[0]}`, e instanceof Error ? e.message : e);
      return null;
    }
  }
  // Partial upsert: PostgREST only writes the columns in the payload.
  private async upsert(table: string, row: Record<string, unknown>, conflict = "user_id,day"): Promise<boolean> {
    return (await this.send("POST", `${table}?on_conflict=${conflict}`, { user_id: this.uid, ...row }, "resolution=merge-duplicates,return=minimal")) !== null;
  }
  private idOf(rows: unknown[] | null): string | null {
    return (rows?.[0] as { id?: string } | undefined)?.id ?? null;
  }

  async settings(): Promise<SettingsRow | null> {
    const rows = await this.get<Record<string, unknown>>(`overseer_settings?${this.u}&select=*`);
    if (!rows) return null;
    const r = rows[0] ?? {};
    const d = DEFAULT_SETTINGS;
    const num = (v: unknown, def: number) => (v === undefined || v === null || Number.isNaN(Number(v)) ? def : Number(v));
    const str = (v: unknown, def: string) => (typeof v === "string" && v ? v : def);
    return {
      tz: str(r.tz, d.tz),
      wake: str(r.wake, d.wake),
      wrap: str(r.wrap, d.wrap),
      ping_kinds: Array.isArray(r.ping_kinds) ? (r.ping_kinds as string[]) : d.ping_kinds,
      ping_every_min: num(r.ping_every_min, d.ping_every_min),
      cap_usd: num(r.cap_usd, d.cap_usd),
      cheap_model: str(r.cheap_model, d.cheap_model),
      smart_model: str(r.smart_model, d.smart_model),
      paused: r.paused === true,
      dry_run: r.dry_run === undefined ? d.dry_run : r.dry_run === true,
      chat_id: r.chat_id === null || r.chat_id === undefined ? null : Number(r.chat_id),
      link_code: typeof r.link_code === "string" ? r.link_code : null,
    };
  }
  patchSettings(p: Partial<SettingsRow>) {
    return this.upsert("overseer_settings", { ...p, updated_at: nowIso() }, "user_id");
  }
  async day(day: string): Promise<DayRow | "none" | null> {
    const rows = await this.get<{ items: unknown; blocks_seeded: boolean; top3: unknown }>(`nights?${this.u}&day=eq.${day}&select=items,blocks_seeded,top3`);
    if (!rows) return null;
    if (!rows.length) return "none";
    const r = rows[0];
    const top3 = Array.isArray(r.top3) ? r.top3.filter((t): t is string => typeof t === "string" && t.trim().length > 0) : [];
    return { items: r.items, blocks_seeded: r.blocks_seeded === true, top3 };
  }
  saveItems(day: string, items: DayItem[], extra: { blocks_seeded?: boolean } = {}) {
    return this.upsert("nights", { day, items, ...extra });
  }
  mirrorCounts(day: string, done: number, total: number) {
    return this.upsert("game_days", { day, items_done: done, items_total: total });
  }
  setTop3(day: string, top3: string[]) {
    return this.upsert("nights", { day, top3 });
  }
  blocks(weekday: number) {
    return this.get<Block>(`class_blocks?${this.u}&weekday=eq.${weekday}&select=id,label,location,kind,start_t,end_t&order=start_t`);
  }
  goalsDue(day: string) {
    return this.get<{ id: string; title: string }>(`goals?${this.u}&status=eq.active&due=gte.${addDays(day, -7)}&due=lte.${day}&select=id,title&order=due.asc&limit=3`);
  }
  async setGoalDone(goalId: string, done: boolean) {
    const a = await this.send("PATCH", `goals?id=eq.${goalId}&${this.u}`, { status: done ? "done" : "active", updated_at: nowIso() });
    const b = await this.send("PATCH", `deadlines?goal_id=eq.${goalId}&${this.u}`, { done });
    return a !== null && b !== null;
  }
  async goals(): Promise<GoalRow[] | null> {
    const gs = await this.get<{ id: string; title: string; due: string | null }>(`goals?${this.u}&status=eq.active&select=id,title,due&order=due.asc.nullslast&limit=20`);
    if (!gs) return null;
    if (!gs.length) return [];
    const steps = await this.get<{ id: string; goal_id: string; title: string; done: boolean }>(
      `goal_steps?${this.u}&goal_id=in.(${gs.map((g) => g.id).join(",")})&select=id,goal_id,title,done&order=sort.asc`,
    );
    if (!steps) return null;
    return gs.map((g) => ({ ...g, steps: steps.filter((s) => s.goal_id === g.id).map(({ id, title, done }) => ({ id, title, done })) }));
  }
  async setStepDone(stepId: string, done: boolean) {
    return (await this.send("PATCH", `goal_steps?id=eq.${stepId}&${this.u}`, { done })) !== null;
  }
  async addStep(goalId: string, title: string) {
    return this.idOf(await this.send("POST", "goal_steps", { user_id: this.uid, goal_id: goalId, title }, "return=representation"));
  }
  async deleteStep(stepId: string) {
    return (await this.send("DELETE", `goal_steps?id=eq.${stepId}&${this.u}`)) !== null;
  }
  async addCapture(text: string) {
    return this.idOf(await this.send("POST", "captures", { user_id: this.uid, text }, "return=representation"));
  }
  async deleteCapture(id: string) {
    return (await this.send("DELETE", `captures?id=eq.${id}&${this.u}`)) !== null;
  }
  captures() {

  }
```

```ts
// Edits to the shared day list (nights.items). Every edit reads the list
// fresh, writes it sorted, mirrors the score counts, and logs an action with
// what it was before and after, which is what Undo replays.
import { countDone, newItemId, normalizeItems, sortItems, type DayItem } from "../../../src/lib/theGame";
import type { Db } from "./db";
import { isHhmm, secOfDayIn } from "./time";
import type { CalPort, Pending, Plan, Settings } from "./types";

export type ToolCtx = { db: Db; cal: CalPort | null; s: Settings; now: number; plan: Plan };
export type ToolOutcome = { ok: boolean; text: string; action_id?: string | null; pending?: Pending };

export const READ_FAIL: ToolOutcome = { ok: false, text: "Couldn't read the list right now. Nothing changed." };
export const WRITE_FAIL: ToolOutcome = { ok: false, text: "Couldn't save the change. Nothing changed." };
const notFound = (id: string, day: string): ToolOutcome => ({ ok: false, text: `No item ${id} on ${day}.` });

type ItemRef = { day: string; item: DayItem };

const replace = (items: DayItem[], it: DayItem) => (items.some((x) => x.id === it.id) ? items.map((x) => (x.id === it.id ? it : x)) : [...items, it]);
const without = (items: DayItem[], id: string) => items.filter((x) => x.id !== id);

export async function loadDay(ctx: ToolCtx, day: string): Promise<DayItem[] | null> {
  const row = await ctx.db.day(day);
  if (row === null) return null;
  return row === "none" ? [] : normalizeItems(row.items);
}

export async function writeDay(ctx: ToolCtx, day: string, items: DayItem[]): Promise<boolean> {
  const sorted = sortItems(items);
  if (!(await ctx.db.saveItems(day, sorted))) return false;
  await ctx.db.mirrorCounts(day, countDone(sorted), sorted.length);
  if (ctx.plan.day === day) ctx.plan = { ...ctx.plan, items: sorted };
  return true;
}

export async function addItem(ctx: ToolCtx, day: string, what: string, time: string): Promise<ToolOutcome> {
  const text = what.trim().slice(0, 200);
  if (!text) return { ok: false, text: "Nothing to add." };
  const items = await loadDay(ctx, day);
  if (!items) return READ_FAIL;
  const it: DayItem = { id: newItemId(), time: isHhmm(time) ? time : "", what: text, done: false, src: "plan" };
  if (!(await writeDay(ctx, day, [...items, it]))) return WRITE_FAIL;
  const action_id = await ctx.db.logAction({ tool: "add_item", summary: `Added "${text}"${it.time ? ` at ${it.time}` : ""} (${day})`, before: null, after: { day, item: it } });
  return { ok: true, text: `Added "${text}" (id ${it.id}).`, action_id };
}

export async function checkItem(ctx: ToolCtx, day: string, id: string, done: boolean): Promise<ToolOutcome> {
  const items = await loadDay(ctx, day);
  if (!items) return READ_FAIL;
  const it = items.find((x) => x.id === id);
  if (!it) return notFound(id, day);
  const next: DayItem = { ...it, done, at: done ? secOfDayIn(ctx.now, ctx.s.tz) : undefined };
  if (!(await writeDay(ctx, day, replace(items, next)))) return WRITE_FAIL;
  if (it.goal_id) await ctx.db.setGoalDone(it.goal_id, done);
  const action_id = await ctx.db.logAction({ tool: "check_item", summary: `${done ? "Checked off" : "Reopened"} "${it.what}"`, before: { day, item: it }, after: { day, item: next } });
  return { ok: true, text: `${done ? "Done" : "Reopened"}: ${it.what}.`, action_id };
}

export async function editItem(ctx: ToolCtx, day: string, id: string, patch: { what?: string; time?: string }): Promise<ToolOutcome> {
  const items = await loadDay(ctx, day);
  if (!items) return READ_FAIL;
  const it = items.find((x) => x.id === id);
  if (!it) return notFound(id, day);
  const what = patch.what !== undefined ? patch.what.trim().slice(0, 200) : it.what;
  if (!what) return { ok: false, text: "The item needs some text." };
  const time = patch.time === undefined ? it.time : patch.time === "" ? "" : isHhmm(patch.time) ? patch.time : it.time;
  const next: DayItem = { ...it, what, time };
  if (!(await writeDay(ctx, day, replace(items, next)))) return WRITE_FAIL;
  const action_id = await ctx.db.logAction({ tool: "edit_item", summary: `Changed "${it.what}"`, before: { day, item: it }, after: { day, item: next } });
  return { ok: true, text: `Updated: ${what}${time ? ` at ${time}` : ""}.`, action_id };
}

// time: "" makes it untimed, "HH:MM" sets it, anything else keeps it.
export async function moveItem(ctx: ToolCtx, fromDay: string, id: string, toDay: string, time: string): Promise<ToolOutcome> {
  const items = await loadDay(ctx, fromDay);
  if (!items) return READ_FAIL;
  const it = items.find((x) => x.id === id);
  if (!it) return notFound(id, fromDay);
  const moved: DayItem = { ...it, time: time === "" ? "" : isHhmm(time) ? time : it.time, done: false, at: undefined };
  if (toDay === fromDay) {
    if (!(await writeDay(ctx, fromDay, replace(items, moved)))) return WRITE_FAIL;
    const action_id = await ctx.db.logAction({ tool: "move_item", summary: `Moved "${it.what}"${moved.time ? ` to ${moved.time}` : " to later today"}`, before: { day: fromDay, item: it }, after: { day: toDay, item: moved } });
    return { ok: true, text: `Moved "${it.what}".`, action_id };
  }
  const target = await loadDay(ctx, toDay);
  if (!target) return READ_FAIL;
  const { block_id: _block, ...rest } = moved;
  const copy: DayItem = { ...rest, id: newItemId(), src: "plan" };
  if (!(await writeDay(ctx, toDay, [...target, copy]))) return WRITE_FAIL;
  if (!(await writeDay(ctx, fromDay, without(items, id)))) {
    await writeDay(ctx, toDay, target);
    return WRITE_FAIL;
  }
  const action_id = await ctx.db.logAction({ tool: "move_item", summary: `Moved "${it.what}" to ${toDay}`, before: { day: fromDay, item: it }, after: { day: toDay, item: copy } });
  return { ok: true, text: `Moved "${it.what}" to ${toDay}.`, action_id };
}

export async function removeItem(ctx: ToolCtx, day: string, id: string): Promise<ToolOutcome> {
  const items = await loadDay(ctx, day);
  if (!items) return READ_FAIL;
  const index = items.findIndex((x) => x.id === id);
  if (index < 0) return notFound(id, day);
  const it = items[index];
  if (!(await writeDay(ctx, day, without(items, id)))) return WRITE_FAIL;
  const action_id = await ctx.db.logAction({ tool: "remove_item", summary: `Removed "${it.what}" (${day})`, before: { day, item: it, index }, after: null });
  return { ok: true, text: `Removed "${it.what}".`, action_id };
}

export async function setTop3(ctx: ToolCtx, day: string, top3: string[]): Promise<ToolOutcome> {
  const row = await ctx.db.day(day);
  if (row === null) return READ_FAIL;
  const before = row === "none" ? [] : row.top3;
  const clean = top3.map((t) => t.trim().slice(0, 200)).filter(Boolean).slice(0, 3);
  if (!(await ctx.db.setTop3(day, clean))) return WRITE_FAIL;
  if (ctx.plan.day === day) ctx.plan = { ...ctx.plan, top3: clean };
  const action_id = await ctx.db.logAction({ tool: "set_top3", summary: `Top 3 for ${day}: ${clean.join("; ")}`, before: { day, top3: before }, after: { day, top3: clean } });
  return { ok: true, text: `Top 3 set for ${day}.`, action_id };
}

export async function undoItem(tool: string, before: unknown, after: unknown, ctx: ToolCtx): Promise<boolean> {
  const b = before as (ItemRef & { index?: number; top3?: string[] }) | null;
  const a = after as ItemRef | null;
  if (tool === "set_top3") return !!b && ctx.db.setTop3(b.day, b.top3 ?? []);
  if (tool === "add_item" && a) {
    const items = await loadDay(ctx, a.day);
    return !!items && writeDay(ctx, a.day, without(items, a.item.id));
  }
  if ((tool === "check_item" || tool === "edit_item") && b) {
    const items = await loadDay(ctx, b.day);
    if (!items || !(await writeDay(ctx, b.day, replace(items, b.item)))) return false;
    if (tool === "check_item" && b.item.goal_id) await ctx.db.setGoalDone(b.item.goal_id, !!b.item.done);
    return true;
  }
  if (tool === "move_item" && a && b) {
    if (a.day !== b.day) {
      const t = await loadDay(ctx, a.day);
      if (!t || !(await writeDay(ctx, a.day, without(t, a.item.id)))) return false;
    }
    const f = await loadDay(ctx, b.day);
    return !!f && writeDay(ctx, b.day, replace(f, b.item));
  }
  if (tool === "remove_item" && b) {
    const f = await loadDay(ctx, b.day);
    if (!f) return false;
    const next = [...f];
    next.splice(Math.min(b.index ?? next.length, next.length), 0, b.item);
    return writeDay(ctx, b.day, next);
  }
  return false;
}
```

```ts
const OR_URL = "https://openrouter.ai/api/v1/chat/completions";
// OpenRouter needs max_tokens above the reasoning budget, or a thinking model
// spends the whole allowance thinking and returns nothing (Learn v50 lesson).
const REASON = 1024;

export function openRouter(key: string, f: typeof fetch = fetch): LlmPort {
  return {
    async chat(model, messages, tools, maxTokens = 600) {
      const empty = { text: "", tool_calls: [] as ToolCall[], cost: 0, tin: 0, tout: 0 };
      try {
        const r = await f(OR_URL, {
          method: "POST",
          headers: { Authorization: `Bearer ${key}`, "Content-Type": "application/json", "HTTP-Referer": "https://bookcrewcode.github.io/daily/", "X-Title": "Daily Overseer" },
          body: JSON.stringify({
            model, messages, ...(tools?.length ? { tools } : {}),
            max_tokens: REASON + maxTokens, reasoning: { max_tokens: REASON, exclude: true }, usage: { include: true },
          }),
          signal: AbortSignal.timeout(45_000),
        });
        if (r.status === 402) return { ...empty, error: "out_of_credit" };
        if (!r.ok) return { ...empty, error: `http_${r.status}` };
        const j = (await r.json()) as any;
        const m = j?.choices?.[0]?.message ?? {};
        const u = j?.usage ?? {};
        return {
          text: typeof m.content === "string" ? m.content : "",
          tool_calls: Array.isArray(m.tool_calls) ? (m.tool_calls as ToolCall[]) : [],
          cost: Number(u.cost) || 0, tin: Number(u.prompt_tokens) || 0, tout: Number(u.completion_tokens) || 0, error: null,
        };
      } catch (e) {
        return { ...empty, error: e instanceof Error && e.name === "TimeoutError" ? "timeout" : "network" };
      }
    },
  };
}

export async function runAgentLoop(a: {
  llm: LlmPort; model: string; messages: Msg[]; tools: ToolSpec[];
  exec: (name: string, args: Record<string, unknown>) => Promise<string>; maxSteps?: number; maxTokens?: number;
}): Promise<{ text: string; cost: number; tin: number; tout: number; error: string | null }> {
  const msgs = [...a.messages];
  let cost = 0, tin = 0, tout = 0, last = "";
  for (let i = 0; i < (a.maxSteps ?? 4); i++) {
    const r = await a.llm.chat(a.model, msgs, a.tools, a.maxTokens ?? 400);
    cost += r.cost; tin += r.tin; tout += r.tout;
    if (r.error) return { text: "", cost, tin, tout, error: r.error };
    last = r.text;
    if (!r.tool_calls.length) return { text: r.text, cost, tin, tout, error: null };
    msgs.push({ role: "assistant", content: r.text || null, tool_calls: r.tool_calls });
    for (const call of r.tool_calls) {
      let args: Record<string, unknown> = {};
      try {
        const p = JSON.parse(call.function.arguments || "{}");
        if (p && typeof p === "object") args = p as Record<string, unknown>;
      } catch {
        // broken arguments: run the tool with none, it answers with what it needs
      }
      msgs.push({ role: "tool", tool_call_id: call.id, content: await a.exec(call.function.name, args) });
    }
  }
  return { text: last, cost, tin, tout, error: null };
}

export function parseJson(text: string): any {
  const a = text.indexOf("{");
  const b = text.lastIndexOf("}");
  if (a < 0 || b <= a) return null;
  try {
    return JSON.parse(text.slice(a, b + 1));
  } catch {
    return null;
  }
}
```

```ts
// The three places the Overseer asks a model for words: the morning plan
// (smart model), the evening wrap note (smart) and a two-minute first step
// (cheap). Each checks the day's cap first and records what it spent. A
// null answer means "use the template", never "say nothing".
import { overCap } from "./budget";
import type { Db } from "./db";
import { parseJson, type LlmPort } from "./llm";

export type Spend = { db: Db; llm: LlmPort; day: string; cap: number };

// A failed call is recorded too (purpose "<purpose>:error:<reason>"), so the
// Overseer page can say the AI couldn't be reached today.
export async function recordSpend(db: Db, day: string, model: string, purpose: string, r: { cost: number; tin: number; tout: number; error?: string | null }) {
  if (r.error) await db.addSpend({ day, model, purpose: `${purpose}:error:${r.error}`, cost_usd: r.cost, tokens_in: r.tin, tokens_out: r.tout });
  else if (r.cost > 0 || r.tin > 0) await db.addSpend({ day, model, purpose, cost_usd: r.cost, tokens_in: r.tin, tokens_out: r.tout });
}

const STYLE = "Plain words. No emojis. No hype. Never shame. Write in English.";

async function once(sp: Spend, model: string, purpose: string, system: string, user: string, maxTokens: number): Promise<string | null> {
  if (!model || overCap(await sp.db.spent(sp.day), sp.cap)) return null;
  const r = await sp.llm.chat(model, [{ role: "system", content: system }, { role: "user", content: user }], undefined, maxTokens);
  await recordSpend(sp.db, sp.day, model, purpose, r);
  return r.error ? null : r.text.trim() || null;
}

export async function morningPlan(
  sp: Spend, model: string, tasks: { n: number; what: string; time: string }[], top3: string[], calendar: string[],
): Promise<{ steps: { n: number; step: string }[]; stakes: number[]; note: string } | null> {
  if (!tasks.length) return null;
  const text = await once(sp, model, "morning", `You plan Ben's day. ${STYLE} Reply with JSON only.`, [
    "Tasks:", ...tasks.map((t) => `${t.n}. ${t.time ? `${t.time} ` : ""}${t.what}`),
    `Top 3 for today: ${top3.join("; ") || "none"}`,
    `Calendar: ${calendar.join("; ") || "none"}`,
    "For each task give the smallest concrete first step, at most 12 words. Pick up to 2 task numbers that matter most to put stakes on (prefer top-3 matches and deadlines). Add one short sentence about the day.",
    'JSON shape: {"steps":[{"n":1,"step":"..."}],"stakes":[1],"note":"..."}',
  ].join("\n"), 700);
  const j = text ? parseJson(text) : null;
  if (!j || !Array.isArray(j.steps)) return null;
  const valid = (n: unknown): n is number => Number.isInteger(n) && (n as number) >= 1 && (n as number) <= tasks.length;
  return {
    steps: j.steps
      .filter((x: any) => valid(x?.n) && typeof x?.step === "string" && x.step.trim())
      .map((x: any) => ({ n: x.n as number, step: String(x.step).trim().slice(0, 120) })),
    stakes: (Array.isArray(j.stakes) ? j.stakes : []).filter(valid).slice(0, 2),
    note: typeof j.note === "string" ? j.note.trim().slice(0, 200) : "",
  };
}

export function wrapNote(sp: Spend, model: string, done: string[], open: string[], moved: string[]): Promise<string | null> {
  return once(sp, model, "wrap", `You close Ben's day. ${STYLE}`, [
    `Done: ${done.join("; ") || "nothing"}`,
    `Still open: ${open.join("; ") || "nothing"}`,
    `Moved: ${moved.join("; ") || "nothing"}`,
    "Write two or three short sentences: wins first, then what is still open. No day counts, no 'you failed'.",
  ].join("\n"), 250);
}

export async function shrinkStep(sp: Spend, model: string, what: string): Promise<string | null> {
  const t = await once(sp, model, "stuck", `You help Ben start. ${STYLE}`, `Give the smallest two-minute first step to start this task, at most 12 words, no preamble. Task: ${what}`, 80);
  if (!t) return null;
  return t.split("\n")[0].replace(/^["'\s-]+|["'\s]+$/g, "").slice(0, 120) || null;
}
```

```ts
export async function handle(st: State, e: Event, d: Deps): Promise<{ state: State; out: Out[] }> {
  const out: Out[] = [];
  if (e.kind === "inbound" && e.ev.update_id <= st.last_update_id) return { state: st, out };
  const s = await d.db.settings();
  if (!s) return { state: st, out };
  if (e.kind === "inbound") st = { ...st, last_update_id: e.ev.update_id };
  const now = d.now();

function newDay(st: State, day: string): State {

// ── the minute tick ─────────────────────────────────────────────────────────

async function tick(st: State, d: Deps, s: Settings, L: Local, now: number, out: Out[]): Promise<State> {
  st = await countdownStep(st, d, s, now, out);      // a started countdown runs even while paused
  if (s.paused) return st;
  const p = st.plan!;
  if (!p.morning_sent) return L.hhmm >= s.wake && L.hhmm < s.wrap ? morning(st, d, s, L, out) : st;
  if (p.wrap_sent) return st;
  if (L.hhmm >= s.wrap) return wrap(st, d, s, L, out);
  st = await learnStep(st, d, L, out);
  return drill(st, d, s, L, now, out);
}

// Re-read the day list. A failed read keeps the cached copy: never "nothing to do".
async function refresh(p: Plan, d: Deps, weekday: number, seed: boolean): Promise<Plan> {
  const [row, blocks] = await Promise.all([d.db.day(p.day), d.db.blocks(weekday)]);
  if (row === null) return p;
  const raw = row === "none" ? [] : row.items;
  let items = normalizeItems(raw);
  if (seed) {
    const r = seedDay(raw, row === "none" ? false : row.blocks_seeded, blocks, await d.db.goalsDue(p.day));
    if (r.changed && (await d.db.saveItems(p.day, sortItems(r.items), { blocks_seeded: r.blocks_seeded }))) {
      items = r.items;
      await d.db.mirrorCounts(p.day, countDone(items), items.length);
    }
  }
  return { ...p, items: sortItems(items), blocks: blocks ?? p.blocks, top3: row === "none" ? [] : row.top3, refreshed_at: d.now() };
}

async function morning(st: State, d: Deps, s: Settings, L: Local, out: Out[]): Promise<State> {
  let p = await refresh(st.plan!, d, L.weekday, true);
  const wins = windowsOf(p, s);
  const byId = new Map(p.items.map((i) => [i.id, i] as const));
  const floatIds = floatingOf(p.items, p.top3, p.bumped).slice(0, 5);
  const tasks = [...wins.map((w) => w.own), ...floatIds].map((id) => byId.get(id)).filter((i): i is DayItem => !!i);
  const cal = d.cal ? await d.cal.listDay(p.day, s.tz) : null;
  const calLines = (cal ?? []).map((ev) => `${ev.start.length > 10 ? ev.start.slice(11, 16) : "all day"} ${ev.title}`);
  const [lines, partners, learn] = await Promise.all([d.db.lines(), d.db.partners(), d.db.learn(p.day)]);
  const stakesReady = !!lines?.length && activePartners(partners ?? []).length > 0;
  const ai = await morningPlan(spendOf(d, s, p.day), s.smart_model, tasks.map((t, i) => ({ n: i + 1, what: t.what, time: t.time })), p.top3, calLines);
  const steps: Record<string, string> = {};
  let suggested = wins.slice(0, 2).map((w) => w.own);
  if (ai) {
    for (const { n, step } of ai.steps) {
      const t = tasks[n - 1];
      if (t) steps[t.id] = step;
    }
    suggested = ai.stakes.map((n) => tasks[n - 1]?.id).filter((x): x is string => !!x).slice(0, 2);
  }
  if (!stakesReady) suggested = [];
  p = { ...p, first_steps: steps, suggested_stakes: suggested, morning_sent: true, learn: learn ? { on: learn.on, at: learn.at } : null };
  const hh = (ms: number) => localOf(ms, s.tz).hhmm;
  out.push(ben(morningText({
    wins: wins.map((w) => ({ start: hh(w.start), end: hh(w.end), what: w.label, step: steps[w.own] ?? T.defaultStep() })),
    floating: floatIds.map((id) => byId.get(id)?.what ?? "").filter(Boolean),
    top3: p.top3,
    calendar: calLines,
    stakes: suggested.map((id) => byId.get(id)?.what ?? ""),
    note: ai?.note ?? "",
    stakesMissing: !stakesReady,
    learnAt: p.learn?.on ? p.learn.at : null,
  }), morningButtons(p.day)));
  return { ...st, plan: p };
}

async function learnStep(st: State, d: Deps, L: Local, out: Out[]): Promise<State> {
  const p = st.plan!;
  if (!p.learn?.on || p.learn_nudged || L.hhmm < p.learn.at) return st;
  const info = await d.db.learn(p.day);
  if (!info) return st;                       // a failed read skips: silence beats a nag
  if (!info.done) out.push(ben(T.learn(), learnButtons()));
  return { ...st, plan: { ...p, learn_nudged: true } };
}

async function drill(st: State, d: Deps, s: Settings, L: Local, now: number, out: Out[]): Promise<State> {
  let p = st.plan!;
  if (now - p.refreshed_at >= 5 * MIN) p = await refresh(p, d, L.weekday, false);
  const win = windowAt(windowsOf(p, s), now);
  if (!win) return { ...st, plan: p, ladder: st.ladder.win ? EMPTY_LADDER : st.ladder };
  if (!p.locked) p = { ...p, locked: true, stakes: [] };    // unanswered morning: tasks lock, no stakes
  st = { ...st, plan: p };
  const cur = st.ladder.task ? p.items.find((i) => i.id === st.ladder.task) : undefined;
  if (st.ladder.win !== win.key || !cur || cur.done) return startNext(st, s, now, out, win);
  const r = onTick(st.ladder, now, s.ping_every_min);
  if (r.effect.kind === "none") return st;
  // something is due: read the list again so a task ticked in the app never gets pinged
  p = await refresh(p, d, L.weekday, false);
  st = { ...st, plan: p };
  const fresh = p.items.find((i) => i.id === cur.id);
  if (!fresh || fresh.done) return startNext(st, s, now, out, windowAt(windowsOf(p, s), now));
  if (r.effect.kind === "ping") {
    out.push(ben(r.effect.step === 0 ? T.ping(fresh.what) : T.still(fresh.what), drillButtons(fresh.id)));
    return { ...st, ladder: r.ladder };
  }
  if (r.effect.kind === "shrink") {
    out.push(ben(T.shrink(p.first_steps[fresh.id] ?? T.defaultStep()), shrinkButtons(fresh.id)));
    return { ...st, ladder: r.ladder };
  }
  return escalate({ ...st, ladder: r.ladder }, d, s, fresh, win, now, out);
}

function startNext(st: State, s: Settings, now: number, out: Out[], win: Win | null): State {
  const p = st.plan!;
  if (!win) return { ...st, ladder: EMPTY_LADDER };
  const task = taskFor(win, p.items, floatingOf(p.items, p.top3, p.bumped));
  if (!task) {
    if (st.ladder.task) out.push(ben(T.nothingLeft()));
    return { ...st, ladder: { ...EMPTY_LADDER, win: win.key } };
  }
  if (task.id === st.ladder.task && st.ladder.win === win.key) return st;
  out.push(ben(T.start(task.what, p.first_steps[task.id] ?? T.defaultStep()), startButtons(task.id)));
  return { ...st, ladder: startTask(win.key, task.id, now) };
}

async function escalate(st: State, d: Deps, s: Settings, task: DayItem, win: Win, now: number, out: Out[]): Promise<State> {
  if (st.countdown) return st;
  const p = st.plan!;
  const [lines, partners] = await Promise.all([d.db.lines(), d.db.partners()]);
  if (lines && partners && canStake({ plan: p, itemId: task.id, day: p.day, sentDay: st.stakes_sent_day, lines, partners })) {
    const line = pickLine(lines)!;
    const partner = pickPartner(partners)!;
    out.push(ben(T.countdown(partner.name, lines.findIndex((l) => l.id === line.id) + 1), shrinkButtons(task.id)));
    await d.db.logStakes({ day: p.day, item_id: task.id, what: task.what, status: "started", line_id: line.id, partner_id: partner.id });
    return { ...st, countdown: { task: task.id, what: task.what, win: win.key, ends_at: win.end, fires_at: now + COUNTDOWN_MIN * MIN, line_id: line.id, partner_id: partner.id } };
  }
  return reshuffle(st, d, s, task, now, out, true);
}

async function countdownStep(st: State, d: Deps, s: Settings, now: number, out: Out[]): Promise<State> {
  const c = st.countdown;
  if (!c) return st;
  const day = st.plan!.day;
  const log = (status: "cancelled" | "sent" | "voided") => d.db.logStakes({ day, item_id: c.task, what: c.what, status, line_id: c.line_id, partner_id: c.partner_id });
  if (now >= c.ends_at) {
    out.push(ben(T.countdownOver()));
    await log("cancelled");
    return { ...st, countdown: null };
  }
  if (now < c.fires_at) return st;
  const [lines, partners] = await Promise.all([d.db.lines(), d.db.partners()]);
  const line = lines?.find((l) => l.id === c.line_id);
  const partner = partners ? activePartners(partners).find((p) => p.id === c.partner_id) : undefined;
  let next: State = { ...st, countdown: null };
  if (st.stakes_sent_day !== day && line && partner && partner.chat_id !== null) {
    out.push({ chat: partner.chat_id, text: T.partner(line.text) });
    out.push(ben(T.stakesSent(partner.name)));
    await Promise.all([log("sent"), d.db.bumpLine(line.id, line.used + 1), d.db.bumpPartner(partner.id, partner.sent + 1)]);
    next = { ...next, stakes_sent_day: day };
  } else {
    await log("voided");
  }
  const task = st.plan!.items.find((i) => i.id === c.task);
  return task && !task.done ? reshuffle(next, d, s, task, now, out, !s.paused) : next;
}

// Move a task: to the next drill block today if there is one (untimed, first
// in line), otherwise to tomorrow.
async function reshuffle(st: State, d: Deps, s: Settings, task: DayItem, now: number, out: Out[], andNext: boolean): Promise<State> {
  const p = st.plan!;
  const later = nextWindowAfter(windowsOf(p, s).filter((w) => w.own !== task.id), now);
  const ctx = ctxOf(st, d, s, now);
  const res = await moveItem(ctx, p.day, task.id, later ? p.day : addDays(p.day, 1), "");
  if (!res.ok) {
    out.push(ben(`Couldn't move "${task.what}". It stays where it is.`));
    return { ...st, plan: ctx.plan, ladder: { ...st.ladder, step: 0, awaiting: false, next_at: now + s.ping_every_min * MIN } };
  }
  out.push(ben(T.moved(task.what, later ? `to later today. It's queued for your ${localOf(later.start, s.tz).hhmm} block` : "to tomorrow")));
  const plan: Plan = {
    ...ctx.plan,
    bumped: later ? [task.id, ...ctx.plan.bumped.filter((x) => x !== task.id)] : ctx.plan.bumped,
    moved: [...ctx.plan.moved, { what: task.what, to: later ? "later today" : "tomorrow" }],
  };
  const next: State = { ...st, plan };
  if (!andNext) return next;
  return startNext({ ...next, ladder: { ...next.ladder, task: null } }, s, now, out, windowAt(windowsOf(plan, s), now));
}

async function wrap(st: State, d: Deps, s: Settings, L: Local, out: Out[]): Promise<State> {
  const p = await refresh(st.plan!, d, L.weekday, false);
  const done = p.items.filter((i) => i.done).map((i) => i.what);
  const open = p.items.filter((i) => !i.done).map((i) => i.what);
  const moved = p.moved.map((m) => `${m.what} (${m.to})`);
  const learn = p.learn?.on ? await d.db.learn(p.day) : null;
  const note = await wrapNote(spendOf(d, s, p.day), s.smart_model, done, open, moved);
  out.push(ben(wrapText({
    done, open, moved,
    pauses: st.pauses.map((t) => localOf(t, s.tz).hhmm),
    note: note ?? "",
    learn: learn ? (learn.done ? "done" : "not done yet") : null,
  })));
  return { ...st, plan: { ...p, wrap_sent: true }, ladder: EMPTY_LADDER, awaiting_top3_for: addDays(p.day, 1) };
}

async function inbound(st: State, d: Deps, s: Settings, ev: Inbound, L: Local, now: number, out: Out[]): Promise<State> {
  const partners = (await d.db.partners()) ?? [];
  const who = classify(ev, s.chat_id, activePartners(partners).map((p) => p.chat_id as number));
  if (who.role === "ignore" || ev.kind === "other") return st;
  await d.db.logMessage({
    direction: "in", peer: who.role === "join" || who.role === "leave" ? "partner" : "ben",
    text: ev.kind === "text" ? ev.text : `[tap] ${ev.data}`, buttons: null, dry_run: false,
  });
  if (who.role === "link") {
    if (s.link_code && who.code === s.link_code && (await d.db.patchSettings({ chat_id: ev.chat_id, link_code: null }))) {
      out.push({ chat: ev.chat_id, text: T.linked(), force: true });
    }
    return st;
  }
  if (who.role === "join") {
    const p = await d.db.joinPartner(who.code, ev.chat_id);
    if (p) {
      out.push({ chat: ev.chat_id, text: T.partnerWelcome(), force: true });
      out.push(ben(T.partnerJoined(p.name)));
    }
    return st;
  }
  if (who.role === "leave") {
    const name = await d.db.leavePartner(ev.chat_id);
    if (name) {
      out.push({ chat: ev.chat_id, text: T.partnerBye(), force: true });
      out.push(ben(T.partnerLeft(name)));
    }
    return st;
  }
  // Ben: any tap or message means he's here, so the silence ladder resets
  if (st.ladder.task) st = { ...st, ladder: onAnswer(st.ladder, now, s.ping_every_min, "message") };
  return ev.kind === "tap" ? onTap(st, d, s, ev, now, out) : onText(st, d, s, ev.text, L, now, out);
}

async function onTap(st: State, d: Deps, s: Settings, ev: Extract<Inbound, { kind: "tap" }>, now: number, out: Out[]): Promise<State> {
  out.push({ chat: "ben", text: "", answer: ev.callback_id });
  const c = parseCb(ev.data);
  if (!c) return st;
  const p = st.plan!;
  switch (c.act) {
    case "done":
      return markDone(st, d, s, c.arg, now, out);
    case "onit":
      out.push(ben("Good. I'll check in later."));
      return st;
    case "more":
      out.push(ben("OK. Back in 10."));
      return { ...st, ladder: onAnswer(st.ladder, now, s.ping_every_min, "more") };
    case "stuck": {
      const item = p.items.find((i) => i.id === c.arg);
      const step = (item && (await shrinkStep(spendOf(d, s, p.day), s.cheap_model, item.what))) ?? p.first_steps[c.arg] ?? T.defaultStep();
      out.push(ben(T.shrink(step), shrinkButtons(c.arg)));
      return { ...st, plan: { ...p, first_steps: { ...p.first_steps, [c.arg]: step } }, ladder: onAnswer(st.ladder, now, s.ping_every_min, "stuck") };
    }
    case "skip": {
      const item = p.items.find((i) => i.id === c.arg && !i.done);
      return item ? reshuffle(st, d, s, item, now, out, st.ladder.task === item.id) : st;
    }
    case "lock":
      if (p.locked) {
        out.push(ben("Already locked."));
        return st;
      }
      out.push(ben(T.locked(p.suggested_stakes.map((id) => p.items.find((i) => i.id === id)?.what ?? ""))));
      return { ...st, plan: { ...p, locked: true, stakes: p.suggested_stakes } };
    case "change":
      out.push(ben(T.change()));
      return st;
    case "nostakes":
      return stakesOff(st, s, now, out);
    case "yes":
    case "no": {
      const pend = st.pending.find((x) => x.id === c.arg);
      if (!pend) {
        out.push(ben("That request expired."));
        return st;
      }
      const rest = st.pending.filter((x) => x.id !== c.arg);
      if (c.act === "no") {
        out.push(ben("Left as is."));
        return { ...st, pending: rest };
      }
      const ctx = ctxOf(st, d, s, now);
      out.push(ben((await confirmPending(pend, ctx)).text));
      return { ...st, plan: ctx.plan, pending: rest };
    }
  }
  return st;
}

async function markDone(st: State, d: Deps, s: Settings, id: string, now: number, out: Out[]): Promise<State> {
  const ctx = ctxOf(st, d, s, now);
  const r = await checkItem(ctx, st.plan!.day, id, true);
  if (!r.ok) {
    out.push(ben(r.text));
    return st;
  }
  let next: State = { ...st, plan: ctx.plan };
  const c = st.countdown;
  if (c && c.task === id) {
    await d.db.logStakes({ day: ctx.plan.day, item_id: id, what: c.what, status: "cancelled", line_id: c.line_id, partner_id: c.partner_id });
    out.push(ben(T.countdownStopped()));
    next = { ...next, countdown: null };
  }
  out.push(ben(r.text));
  if (st.ladder.task !== id) return next;
  return startNext(next, s, now, out, windowAt(windowsOf(ctx.plan, s), now));
}

function stakesOff(st: State, s: Settings, now: number, out: Out[]): State {
  const p = st.plan!;
  if (!stakesOffAllowed(firstWindowStart(p, s), now)) {
    out.push(ben(T.tooLateStakes()));
    return st;
  }
  out.push(ben(T.locked([])));
  return { ...st, plan: { ...p, stakes_off: true, locked: true, stakes: [] } };
}

async function onText(st: State, d: Deps, s: Settings, raw: string, L: Local, now: number, out: Out[]): Promise<State> {
  const t = raw.trim();
  if (t.startsWith("/")) return command(st, d, s, t.toLowerCase(), L, now, out);
  if (st.awaiting_top3_for) {
    const lines = t.split("\n").map((x) => x.replace(/^\s*(\d+[.)]|[-*])\s*/, "").trim()).filter(Boolean).slice(0, 3);
    if (lines.length) {
      const r = await setTop3(ctxOf(st, d, s, now), st.awaiting_top3_for, lines);
      out.push(ben(r.ok ? T.top3Set(lines.length) : r.text));
      return r.ok ? { ...st, awaiting_top3_for: null } : st;
    }
  }
  return talk(st, d, s, t, now, out);
}

async function command(st: State, d: Deps, s: Settings, t: string, L: Local, now: number, out: Out[]): Promise<State> {
  if (t === "/today") {
    const p = await refresh(st.plan!, d, L.weekday, false);
    out.push(ben(todayText(p.items)));
    return { ...st, plan: p };
  }
  if (t === "/pause") {
    await d.db.patchSettings({ paused: true });
    out.push(ben(T.paused()));
    return { ...st, pauses: [...st.pauses, now], ladder: EMPTY_LADDER };
  }
  if (t === "/resume") {
    await d.db.patchSettings({ paused: false });
    out.push(ben(T.resumed()));
    return { ...st, ladder: EMPTY_LADDER };
  }
  if (t === "/done" || t === "/skip") {
    const id = st.ladder.task;
    if (!id) {
      out.push(ben("Nothing active right now."));
      return st;
    }
    if (t === "/done") return markDone(st, d, s, id, now, out);
    const item = st.plan!.items.find((i) => i.id === id);
    return item ? reshuffle(st, d, s, item, now, out, true) : st;
  }
  if (t === "/stakes off") return stakesOff(st, s, now, out);
  out.push(ben(T.help()));
  return st;
}

export function systemPrompt(p: Plan, s: Settings, now: number, withCal: boolean): string {
  const L = localOf(now, s.tz);

  return [
    "You are Ben's Overseer: a firm, brief day manager. Ben has ADHD; you are his processing speed.",
    "Write plain words in English, no emojis, never shame, at most three short sentences.",
    "When Ben asks for a change inside his own plan, make it with a tool instead of asking. Removing anything, deleting calendar events and changing your own rules need Ben's yes: the tool asks him for you.",

    `Top 3: ${p.top3.join("; ") || "(none)"}`,
    `Stakes today: ${stakes}`,
  ].join("\n");
}

async function talk(st: State, d: Deps, s: Settings, text: string, now: number, out: Out[]): Promise<State> {
  const p = st.plan!;

    return { ...st, cap_notice_day: p.day };
  }
  const ctx = ctxOf(st, d, s, now);
  const pend: Pending[] = [];
  const exec = async (name: string, args: Record<string, unknown>) => {
    const r = await runTool(name, args, ctx, d.ids);
    if (r.pending) pend.push(r.pending);

  const res = await runAgentLoop({ llm: d.llm, model: s.cheap_model, messages, tools: toolSpecs(!!d.cal), exec, maxSteps: 4 });
  await recordSpend(d.db, p.day, s.cheap_model, "talk", res);
  if (res.error) {
    const dry = res.error === "out_of_credit";
    out.push(ben(dry ? T.capNotice() : "I couldn't think that through just now. Buttons and commands still work."));
    return { ...st, plan: ctx.plan, cap_notice_day: dry ? p.day : st.cap_notice_day };
  }
  const answer = res.text.trim() || "Done.";
  out.push(ben(answer));
  for (const x of pend) out.push(ben(T.confirm(x.summary), confirmButtons(x.id)));
  const convo = [...st.convo, { role: "user" as const, content: text }, { role: "assistant" as const, content: answer }].slice(-12);
  return { ...st, plan: ctx.plan, pending: [...st.pending, ...pend].slice(-5), convo };
}

export async function undo(st: State, actionId: string, d: Deps): Promise<{ state: State; ok: boolean; text: string }> {
  const s = await d.db.settings();
  if (!s) return { state: st, ok: false, text: "Couldn't read settings." };
  const a = await d.db.action(actionId);
  if (!a) return { state: st, ok: false, text: "Action not found." };
  if (a.undone_at) return { state: st, ok: true, text: "Already undone." };
  const now = d.now();
  const ctx: ToolCtx = { db: d.db, cal: d.cal, s, now, plan: st.plan ?? blankPlan(localOf(now, s.tz).day) };
  if (!(await undoAction(a, ctx))) return { state: st, ok: false, text: "Couldn't undo that." };
  await d.db.markUndone(actionId);
  return { state: st.plan ? { ...st, plan: ctx.plan } : st, ok: true, text: "Undone." };
}
```

```ts
// HTTP edge of the Worker. Telegram must carry the webhook secret; the app
// must carry Ben's Supabase session. Anything else is a 404.
import { webhookOk } from "./core/telegram";

export type Stub = {
  inbound(update: unknown): Promise<void>;
  api(op: string, body: Record<string, unknown>, origin: string): Promise<Record<string, unknown>>;
};
export type RouterEnv = { SUPABASE_URL: string; SUPABASE_SERVICE_ROLE_KEY: string; BEN_USER_ID: string; APP_ORIGIN: string; TELEGRAM_WEBHOOK_SECRET: string };

export async function userIdOf(auth: string | null, env: RouterEnv, f: typeof fetch): Promise<string | null> {
  const token = auth?.replace(/^Bearer\s+/i, "").trim() ?? "";
  if (!token) return null;
  try {
    const r = await f(`${env.SUPABASE_URL}/auth/v1/user`, { headers: { apikey: env.SUPABASE_SERVICE_ROLE_KEY, Authorization: `Bearer ${token}` } });
    if (!r.ok) return null;
    return ((await r.json()) as { id?: string }).id ?? null;
  } catch {
    return null;
  }
}

export async function route(req: Request, env: RouterEnv, stub: () => Promise<Stub>, f: typeof fetch = fetch): Promise<Response> {
  const url = new URL(req.url);
  const cors = { "Access-Control-Allow-Origin": env.APP_ORIGIN, "Access-Control-Allow-Headers": "authorization, content-type", "Access-Control-Allow-Methods": "POST, OPTIONS", Vary: "Origin" };
  const json = (b: unknown, status = 200) => new Response(JSON.stringify(b), { status, headers: { "Content-Type": "application/json", ...cors } });

  if (req.method === "OPTIONS") return new Response(null, { status: 204, headers: cors });

  if (url.pathname === "/telegram" && req.method === "POST") {
    if (!webhookOk(req.headers.get("X-Telegram-Bot-Api-Secret-Token"), env.TELEGRAM_WEBHOOK_SECRET)) return new Response("unauthorized", { status: 401 });
    let update: unknown;
    try {
      update = await req.json();
    } catch {
      return new Response("bad request", { status: 400 });
    }
    await (await stub()).inbound(update);
    return new Response("ok");
  }

  if (url.pathname.startsWith("/api/") && req.method === "POST") {
    if ((await userIdOf(req.headers.get("Authorization"), env, f)) !== env.BEN_USER_ID) return json({ ok: false, error: "forbidden" }, 403);
    let body: Record<string, unknown> = {};
    try {
      const b = await req.json();
      if (b && typeof b === "object") body = b as Record<string, unknown>;
    } catch {
      // no body
    }
    return json(await (await stub()).api(url.pathname.slice(5), body, url.origin));
  }

  return new Response("not found", { status: 404 });
}
```

```ts
// The Overseer agent: one Durable Object for Ben. It owns the brain's state,
// a durable inbox (Telegram updates) and outbox (messages still to send),
// and the every-minute tick. Every decision lives in core/brain.ts; this
// file only wires storage, Telegram, Supabase and OpenRouter around it.
import { Agent } from "agents";
import { handle, undo as undoInBrain, type Deps, type Event, type Out } from "./core/brain";
import { SupabaseDb } from "./core/db";
import { openRouter } from "./core/llm";
import { parseUpdate, TgClient } from "./core/telegram";
import { initialState as freshState, type CalPort, type State } from "./core/types";
import type { OverseerEnv } from "./env";

export function randomCode(): string {
  const b = new Uint8Array(12);
  crypto.getRandomValues(b);
  return [...b].map((x) => x.toString(16).padStart(2, "0")).join("");
}

export class Overseer extends Agent<OverseerEnv, State> {
  initialState: State = freshState();
  private chain: Promise<unknown> = Promise.resolve();

  async onStart() {
    this.sql`create table if not exists inbox (id integer primary key autoincrement, body text not null)`;
    this.sql`create table if not exists outbox (id integer primary key autoincrement, body text not null, tries integer not null default 0)`;
    this.sql`create table if not exists kv (k text primary key, v text not null)`;
    await this.schedule("* * * * *", "tick");
  }

  // One state change at a time: alarms and RPC calls interleave at every await.
  private serial<T>(fn: () => Promise<T>): Promise<T> {
    const run = this.chain.then(fn, fn);
    this.chain = run.catch(() => undefined);
    return run;
  }

  private kvGet(k: string): string | null {
    return this.sql<{ v: string }>`select v from kv where k = ${k}`[0]?.v ?? null;
  }
  private kvSet(k: string, v: string | null) {
    if (v === null) this.sql`delete from kv where k = ${k}`;
    else this.sql`insert into kv (k, v) values (${k}, ${v}) on conflict(k) do update set v = excluded.v`;
  }

  private db() {
    return new SupabaseDb(this.env.SUPABASE_URL, this.env.SUPABASE_SERVICE_ROLE_KEY, this.env.BEN_USER_ID);
  }
  private cal(): CalPort | null {
    return null;
  }
  private deps(): Deps {
    return { db: this.db(), llm: openRouter(this.env.OPENROUTER_API_KEY), cal: this.cal(), now: () => Date.now(), ids: () => crypto.randomUUID() };
  }

  private async step(e: Event) {
    try {
      const { state, out } = await handle(this.state, e, this.deps());
      this.setState(state);
      for (const o of out) this.sql`insert into outbox (body) values (${JSON.stringify(o)})`;
    } catch (err) {
      console.error("[overseer] step failed", e.kind, err instanceof Error ? err.message : err);
    }
    await this.flush();
  }

  async tick() {
    await this.serial(() => this.step({ kind: "tick" }));

    await this.serial(async () => {
      const rows = this.sql<{ id: number; body: string }>`select id, body from inbox order by id limit 20`;
      for (const r of rows) {
        this.sql`delete from inbox where id = ${r.id}`;
        await this.step({ kind: "inbound", ev: parseUpdate(JSON.parse(r.body)) });
      }
    });

      else this.sql`update outbox set tries = tries + 1 where id = ${r.id}`;
```

```ts
// Google OAuth (offline access, calendar.events scope only) and a small
// Calendar API client. The refresh token lives in the agent's own storage.
import { addDays, epochOf } from "./core/time";
import type { CalEvent, CalPort } from "./core/types";

export type Tokens = { access_token: string; refresh_token: string; expires_at: number };
export interface TokenStore {
  get(): Promise<Tokens | null>;
  set(t: Tokens): Promise<void>;
}

const AUTH = "https://accounts.google.com/o/oauth2/v2/auth";
const TOKEN = "https://oauth2.googleapis.com/token";
const EVENTS = "https://www.googleapis.com/calendar/v3/calendars/primary/events";
export const SCOPE = "https://www.googleapis.com/auth/calendar.events";
const FORM = { "Content-Type": "application/x-www-form-urlencoded" };

export function authUrl(clientId: string, redirect: string, state: string): string {
  const q = new URLSearchParams({ client_id: clientId, redirect_uri: redirect, response_type: "code", scope: SCOPE, access_type: "offline", prompt: "consent", state });
  return `${AUTH}?${q}`;
}

export async function exchangeCode(code: string, clientId: string, secret: string, redirect: string, f: typeof fetch = fetch, now = Date.now()): Promise<Tokens | null> {
  try {
    const r = await f(TOKEN, { method: "POST", headers: FORM, body: new URLSearchParams({ code, client_id: clientId, client_secret: secret, redirect_uri: redirect, grant_type: "authorization_code" }) });
    if (!r.ok) return null;
    const j = (await r.json()) as { access_token?: string; refresh_token?: string; expires_in?: number };
    if (!j.access_token || !j.refresh_token) return null;
    return { access_token: j.access_token, refresh_token: j.refresh_token, expires_at: now + (j.expires_in ?? 3600) * 1000 };
  } catch {
    return null;
  }
}

export class GoogleCal implements CalPort {
  constructor(private store: TokenStore, private clientId: string, private secret: string, private f: typeof fetch = fetch, private clock: () => number = Date.now) {}

  private async token(): Promise<string | null> {
    const t = await this.store.get();
    if (!t) return null;
    if (t.expires_at - 60_000 > this.clock()) return t.access_token;
    try {
      const r = await this.f(TOKEN, { method: "POST", headers: FORM, body: new URLSearchParams({ client_id: this.clientId, client_secret: this.secret, refresh_token: t.refresh_token, grant_type: "refresh_token" }) });
      if (!r.ok) return null;
      const j = (await r.json()) as { access_token?: string; expires_in?: number };
      if (!j.access_token) return null;
      await this.store.set({ ...t, access_token: j.access_token, expires_at: this.clock() + (j.expires_in ?? 3600) * 1000 });
      return j.access_token;
    } catch {
      return null;
    }
  }

  private async call(method: string, path: string, body?: unknown): Promise<any | null> {
    const tok = await this.token();
    if (!tok) return null;
    try {
      const r = await this.f(`${EVENTS}${path}`, { method, headers: { Authorization: `Bearer ${tok}`, "Content-Type": "application/json" }, body: body === undefined ? undefined : JSON.stringify(body) });
      if (!r.ok) {
        console.error(`[gcal] ${method} ${r.status}`);
        return null;
      }
      return r.status === 204 ? {} : await r.json();
    } catch (e) {
      console.error("[gcal]", e instanceof Error ? e.message : e);
      return null;
    }
  }

  private ev(j: any): CalEvent {
    return { id: String(j.id), title: String(j.summary ?? "(no title)"), start: String(j.start?.dateTime ?? j.start?.date ?? ""), end: String(j.end?.dateTime ?? j.end?.date ?? "") };
  }

  async listDay(day: string, tz: string) {
    const q = new URLSearchParams({
      timeMin: new Date(epochOf(day, "00:00", tz)).toISOString(),
      timeMax: new Date(epochOf(addDays(day, 1), "00:00", tz)).toISOString(),
      singleEvents: "true", orderBy: "startTime", timeZone: tz, maxResults: "50",
    });
    const j = await this.call("GET", `?${q}`);
    return j ? (Array.isArray(j.items) ? j.items.map((x: any) => this.ev(x)) : []) : null;
  }
  async create(title: string, start: string, end: string, tz: string) {
    const j = await this.call("POST", "", { summary: title, start: { dateTime: start, timeZone: tz }, end: { dateTime: end, timeZone: tz } });
    return j ? this.ev(j) : null;
  }
  async move(id: string, start: string, end: string, tz: string) {
    const j = await this.call("PATCH", `/${encodeURIComponent(id)}`, { start: { dateTime: start, timeZone: tz }, end: { dateTime: end, timeZone: tz } });
    return j ? this.ev(j) : null;
  }
  async get(id: string) {
    const j = await this.call("GET", `/${encodeURIComponent(id)}`);
    return j ? this.ev(j) : null;
  }
  async remove(id: string) {
    return (await this.call("DELETE", `/${encodeURIComponent(id)}`)) !== null;
  }
}
```

```ts
// Calendar tools. Creating and moving act right away (with Undo); deleting
// asks Ben first.
import { WRITE_FAIL, type ToolOutcome } from "./dayops";
import { isHhmm, minutesBetween } from "./time";
import { dayArg, dayOf, fn, S, str, type Handler } from "./toolkit";
import type { CalEvent } from "./types";

const NO_CAL: ToolOutcome = { ok: false, text: "Google Calendar isn't connected." };
const CAL_READ_FAIL: ToolOutcome = { ok: false, text: "Couldn't read the calendar right now." };
const local = (day: string, hhmm: string) => `${day}T${hhmm}:00`;
const hhmmOf = (iso: string) => (iso.length > 10 ? iso.slice(11, 16) : "all day");
const timeArg = { type: "string", description: "HH:MM" };

function span(a: Record<string, unknown>): { start: string; end: string } | null {
  const start = str(a.start);
  const end = str(a.end);
  return isHhmm(start) && isHhmm(end) && minutesBetween(start, end) > 0 ? { start, end } : null;
}
const BAD_SPAN: ToolOutcome = { ok: false, text: "Start and end must be HH:MM, with the end after the start." };

export const CAL_HANDLERS: Record<string, Handler> = {
  calendar_list: {
    spec: fn("calendar_list", "Read Google Calendar events for a day, with ids.", { day: dayArg }),
    run: async (a, ctx) => {
      if (!ctx.cal) return NO_CAL;
      const evs = await ctx.cal.listDay(dayOf(a.day, ctx), ctx.s.tz);
      if (!evs) return CAL_READ_FAIL;
      return { ok: true, text: evs.length ? evs.map((e) => `${e.id} | ${hhmmOf(e.start)}-${hhmmOf(e.end)} | ${e.title}`).join("\n") : "No events." };
    },
  },
  calendar_create: {
    spec: fn("calendar_create", "Add an event to Google Calendar.", { title: S, day: dayArg, start: timeArg, end: timeArg }, ["title", "start", "end"]),
    run: async (a, ctx) => {
      if (!ctx.cal) return NO_CAL;
      const t = span(a);
      if (!t) return BAD_SPAN;
      const title = str(a.title).slice(0, 200);
      if (!title) return { ok: false, text: "Need a title." };
      const day = dayOf(a.day, ctx);
      const ev = await ctx.cal.create(title, local(day, t.start), local(day, t.end), ctx.s.tz);
      if (!ev) return WRITE_FAIL;
      const action_id = await ctx.db.logAction({ tool: "calendar_create", summary: `Added "${title}" to the calendar (${day} ${t.start})`, before: null, after: { event_id: ev.id } });
      return { ok: true, text: `Added "${title}" at ${t.start}.`, action_id };
    },
    undo: async (a, ctx) => !!ctx.cal && ctx.cal.remove((a.after as { event_id: string }).event_id),
  },
  calendar_move: {
    spec: fn("calendar_move", "Move a Google Calendar event.", { event_id: S, day: dayArg, start: timeArg, end: timeArg }, ["event_id", "start", "end"]),
    run: async (a, ctx) => {
      if (!ctx.cal) return NO_CAL;
      const t = span(a);
      if (!t) return BAD_SPAN;
      const before = await ctx.cal.get(str(a.event_id));
      if (!before) return { ok: false, text: `No event ${str(a.event_id)}.` };
      const day = dayOf(a.day, ctx);
      const ev = await ctx.cal.move(before.id, local(day, t.start), local(day, t.end), ctx.s.tz);
      if (!ev) return WRITE_FAIL;
```

```ts
import { supabase } from "./supabase";

// The Overseer agent's own API (a Cloudflare Worker). It answers only Ben's
// signed-in session; everything else on the Overseer page reads Supabase.
export const OVERSEER_URL = "https://overseer.<account>.workers.dev";

export type OverseerReply = { ok: boolean; error?: string; text?: string; url?: string; linked?: boolean; paused?: boolean; dry_run?: boolean; google?: boolean };

export async function overseer(op: string, body: Record<string, unknown> = {}): Promise<OverseerReply> {
  const { data } = await supabase.auth.getSession();
  const token = data.session?.access_token;
  if (!token) return { ok: false, error: "Sign in first." };
  try {
    const r = await fetch(`${OVERSEER_URL}/api/${op}`, {
      method: "POST",
      headers: { Authorization: `Bearer ${token}`, "Content-Type": "application/json" },
      body: JSON.stringify(body),
    });
    const j = (await r.json().catch(() => ({}))) as OverseerReply;
    return r.ok ? { ...j, ok: j.ok !== false } : { ok: false, error: j.error ?? `The Overseer answered ${r.status}.` };
  } catch {
    return { ok: false, error: "Couldn't reach the Overseer." };
  }
}
```

- [ ] **Step 1: Replace `src/components/Overseer.tsx`**

```tsx
"use client";

// The Overseer strip: one message, picked for the moment. When the Overseer
// agent (Telegram) has said something to Ben today, its latest message wins,
// so the app and the phone tell the same story. Otherwise the research-tuned
// fallback: morning = gain-framing + yesterday's intention (implementation
// intentions have real ADHD evidence); evening = the streak/loss frame lives
// in the UrgencyCard, so here we stay on patterns and momentum. Never leads
// with failure: RSD-safe by design.

import { useEffect, useState } from "react";
import { supabase, WIN_KEYS, todayStr, dateStr } from "@/lib/supabase";
import { useGame } from "@/lib/useGameData";

const LABEL: Record<string, string> = {
  ws_meds: "Meds", ws_water: "Water", ws_eat: "Clean eating", ws_lift: "Lifts",
  ws_stretch: "Stretching", ws_sleep: "Sleep", ws_vocab: "Vocab", ws_chinese: "Chinese",
  ws_school: "School", ws_affirmations: "Affirmations", ws_work: "BookCrew / work",
};

export default function Overseer({ uid, onOpenChat }: { uid: string; onOpenChat?: (advisor: string) => void }) {
  const game = useGame();
  const [msg, setMsg] = useState<{ head: string; body: string; tone: "warn" | "good" } | null>(null);

  useEffect(() => {
    (async () => {
      const since = new Date(); since.setDate(since.getDate() - 6);
      const midnight = new Date(); midnight.setHours(0, 0, 0, 0);
      const [{ data, error }, { data: todayPlan }, { data: said }] = await Promise.all([
        supabase.from("days").select("*").eq("user_id", uid).gte("day", dateStr(since)),
        supabase.from("nights").select("top3").eq("user_id", uid).eq("day", todayStr()).maybeSingle(),
        supabase.from("overseer_messages").select("text").eq("user_id", uid).eq("direction", "out").eq("peer", "ben")
          .gte("created_at", midnight.toISOString()).order("created_at", { ascending: false }).limit(1),
      ]);
      const last = ((said ?? []) as { text: string }[])[0];
      if (last?.text) {
        setMsg({ head: "Overseer", body: last.text.slice(0, 280), tone: "good" });
        return;
      }
      // read-error guard: a transient failure must not be read as "no wins" —
      // empty rows would fabricate a false "zero taps yet" nudge. Keep whatever
      // message is already on screen and bail rather than treat null as truth.
      if (error) return;
      const rows = data ?? [];
      const today = rows.find((r) => r.day === todayStr());
      const hour = new Date().getHours();
      const todayScore = today ? WIN_KEYS.reduce((s, k) => s + (today[k] ? 1 : 0), 0) : 0;
      const top3 = ((todayPlan?.top3 as string[]) ?? []).filter((t) => t?.trim());

      // weakest habit this week
      const counts: Record<string, number> = {};
      WIN_KEYS.forEach((k) => (counts[k] = rows.reduce((s, r) => s + (r[k] ? 1 : 0), 0)));
      const weakest = [...WIN_KEYS].sort((a, b) => counts[a] - counts[b])[0];
      const weakCount = counts[weakest];

      // MORNING: yesterday-you left instructions. Honor them.
      if (hour < 12 && top3.length > 0 && todayScore < 3) {
        setMsg({
          head: "Overseer",
          body: `Last night you chose: “${top3[0]}”. Don't decide anything — just do its first 2 minutes. Deciding is the trap; starting is the win.`,
          tone: "good",
        });
        return;
      }
      // stalled afternoon — smallest possible re-entry
      if (hour >= 15 && hour < 19 && todayScore === 0) {
        setMsg({ head: "Overseer", body: "Zero taps yet today — that's not failure, that's a blocked start. Break the seal with the easiest toggle on this screen. One tap. Momentum follows action, not the other way around.", tone: "warn" });
        return;
      }
      // strong day — bank the identity, not just the points. After 7pm the
      // UrgencyCard owns the "streak on the line" story; don't contradict it.
      if (todayScore >= Math.ceil(WIN_KEYS.length * 0.7) && (hour < 19 || todayScore === WIN_KEYS.length)) {
        setMsg({ head: "Overseer", body: `${todayScore}/${WIN_KEYS.length} today. This is what consistent looks like — remember this feeling tomorrow morning.`, tone: "good" });
        return;
      }
      // recurring weak link — pattern, not character
      if (weakCount <= 2 && rows.length >= 3) {
        setMsg({ head: "Overseer", body: `${LABEL[weakest] ?? weakest} keeps slipping — ${weakCount}/7 days this week. That's a pattern, not a flaw. Do it FIRST tomorrow, before anything gets a vote.`, tone: "warn" });
        return;
      }
      setMsg(null);
    })();
    // todayXP moves with every habit tap, so the message re-evaluates as the
    // day changes — a "zero taps yet" nudge must not outlive its truth
  }, [uid, game.streak.streak, game.todayXP]);

  if (!msg) return null;
  const warn = msg.tone === "warn";
  return (
    <div className={`mt-3 rounded-2xl p-4 border ${warn ? "bg-orange-500/10 border-orange-500/40" : "bg-[var(--neon)]/10 border-[var(--neon)]/40"}`}>
      <p className={`text-xs uppercase tracking-widest mb-1 ${warn ? "text-orange-400" : "text-[var(--neon)]"}`}>{msg.head}</p>
      <p className="text-sm font-medium leading-snug whitespace-pre-line">{msg.body}</p>
      {onOpenChat && (
        <button onClick={() => onOpenChat("overseer")}
          className={`mt-2 text-xs font-semibold ${warn ? "text-orange-300" : "text-[var(--neon)]"} underline underline-offset-2`}>
          Talk it through →
        </button>
      )}
    </div>
  );
}
```
