# The Desk — Implementation Plan, Phases 1–2 (ledger, tape, jury, Tonight/Debate/Book)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Desk's core: an honest in-app paper ledger with live prices (stocks/ETFs, crypto spot, BloFin perps), a market-data edge function, a nightly jury of OpenRouter models that produces a verdict and queues trades, and the Tonight / Debate / Book screens.

**Architecture:** Pure, dependency-free TypeScript modules in `src/lib/desk/` hold all ledger, rules, TA, calendar and stats math, unit-tested with `node:test`. Four Supabase edge functions (`tape`, `desk`, `desk-sync`, `desk-review`) carry byte-identical copies of those modules (a script checks the copies) and do only I/O and orchestration. The PWA reads tables directly and calls the functions for actions.

**Tech Stack:** Next.js 16 static export (React 19, Tailwind 4), Supabase (Postgres + RLS, pg_cron, pg_net, Vault, Deno edge functions deployed through the Supabase MCP), OpenRouter chat completions with `json_schema` structured outputs, Yahoo Finance v8 chart / Coinbase Exchange / BloFin public market APIs.

**Spec:** `docs/superpowers/specs/2026-09-07-desk-design.md` (read it first; this plan argues from it). Research: `docs/desk/research/`.

## Global Constraints

- Paper only. No broker keys, no order endpoints, anywhere. Copy in the UI says "paper" on every money number's screen.
- Edge functions: each function's total deploy payload (all files) stays under 44,000 bytes; deploy through the Supabase MCP only; never ask Ben to touch Supabase.
- Every OpenRouter call sets `reasoning: { effort: "low", exclude: true }` explicitly and a generous `max_tokens`; retry ladder: 4xx → retry without the reasoning field; empty content → retry with double `max_tokens`; 503 with `response_format` → retry as prompt-JSON. Read cost from `usage.cost`.
- Fills never use a price the model already saw: stocks fill at the next session's daily-bar open; crypto at the open of the next hourly candle after `decided_at`.
- Both-touched bar → stop first and `ambiguous_bar = true`. Gap through a stop fills at the gap.
- Write-first, celebrate-second; every supabase-js write checks `{ error }`; midnight guards on date-keyed views (GRADING.md).
- No emojis in new screens; existing tokens (`--neon`, `--ok`, `--warn`, `--bad`, `--text-2/3/4`, `.mono`, `.eyebrow`) and primitives (`Card`, `Eyebrow`, `SectionTitle`, `Segmented`, `Sparkline`, `Num`) only; every label explained on screen.

// Copies the pure desk modules into each edge function's lib/ dir, rewriting
// relative imports to Deno's explicit ".ts" form, and fails when a copy drifts.
import { readFileSync, writeFileSync, mkdirSync, existsSync } from "node:fs";
const MODS = ["types", "clock", "ta", "rules", "ledger", "stats", "vote", "playbook"];
const TARGETS = { tape: ["types", "clock", "ta"], desk: ["types", "clock", "rules", "vote", "playbook", "stats"], "desk-sync": ["types", "clock", "ledger", "rules"], "desk-review": ["types", "stats", "playbook"] };

let drift = 0;
for (const [fn, mods] of Object.entries(TARGETS)) {
  const dir = `supabase/functions/${fn}/lib`;
  if (!check) mkdirSync(dir, { recursive: true });
  for (const m of mods) {
    if (!MODS.includes(m)) throw new Error(`unknown module ${m}`);
    const src = readFileSync(`src/lib/desk/${m}.ts`, "utf8").replace(/from "\.\/([a-z]+)"/g, 'from "./$1.ts"');
    const out = `${dir}/${m}.ts`;
    if (check) { if (!existsSync(out) || readFileSync(out, "utf8") !== src) { console.error(`drift: ${out}`); drift++; } }
    else writeFileSync(out, src);
  }
}
if (check && drift) process.exit(1);
console.log(check ? "copies in sync" : "copies written");

   - crypto (spot/perp): `bars 1h` → first bar with `t > Date.parse(decided_at)`; if none yet, skip; if `nowMs − decided > 48h` cancel; fill at `bar.o` with `slippageBps`; `expires_on = new Date(t + horizon_days × 86_400_000).toISOString()`; `funding_at = t` for perps; `liq_price` already set.
4. **Exits.** For each open trade:
   - stock/etf: only when `isNyseOpen(nowMs)` or within 10 minutes after the close: fetch `bars 5m`, keep bars with `t ≥ checked_until` and `t < nowMs − 5 min` (completed bars); time stop first: if `timeStopDue` → close at the current quote with reason `time`; else `scanBars` → close at the event price with the reason and `ambiguous_bar`; update `checked_until` to the last completed bar's end; update `mae_r/mfe_r` via `excursions` over the processed bars (accumulate min/max against stored values).
   - crypto: fetch `bars 1h` (48), keep completed bars with `t ≥ checked_until`; same logic 24/7.
   - closing: `closeTrade(trade, price, bps, reason)` → update the row (`status closed`, exit fields, pnl, pnl_pct, r_multiple, spy_exit); owner desk: `cash += cash_delta`. Then POST `desk-review {mode:"settle", trade_id}` (service role) — ignore failures (a later sync retries any closed trade with `review is null`).
5. **Funding.** For open perps: `times = fundingTimesBetween(funding_at, nowMs)`; if any: rate = `tape funding`; `charge = fundingCharge(notional, rate, side) × times.length`; `funding += charge`, `funding_at = last time`; owner desk: `cash −= charge`.
6. **Marks.** If `etParts(nowMs).hour ≥ 16 && minute ≥ 5` (or any time on a non-trading day after 16:05 for crypto) and no `desk_equity` row for `(today, owner)`: for each owner in (`desk` ∪ owners with any trade): `quotes` for open symbols; `bookEquity(startCash, closedPnl, open, marks)` with `startCash = starting_equity` for desk (cash is tracked, but equity is computed from pnl for consistency) and `100000` for shadows; insert `desk_equity` rows (`pnl_day = equity − yesterday's equity row or starting`, `spy_close` from the SPY quote). For the desk owner also update `desk_accounts.equity`, `peak_equity = max`, and run `haltCheck` (equityYesterday from the previous row, equityWeekStart from the `weekStart(today)` row) → set `halted_until/halt_reason` when it fires.
7. Return the summary. Every DB write checks `ok`; errors are collected into `errors[]` and returned, never swallowed silently.

`quotes` mode: quotes for all open symbols + per-owner `bookEquity` with live marks. `mark` mode: step 6 unconditionally (idempotent by the primary key — use `on_conflict=user_id,day,owner` with `resolution=merge-duplicates`).
